# Org Index — moved

The roster is no longer here. On 2026-08-14 the org stopped being a set of standing agent
definitions and became knowledge carried by one skill.

**Load [`orgagent`](../orgagent/SKILL.md) instead.** It has:

- `references/roster.md` — every role, its parent, its surface, its specialist skills
  (generated by `node ~/.claude/helpers/gen-org-index.mjs`; never hand-edited)
- `references/charters/` — the long-form contract for each role, read only when a routing
  call is genuinely close
- `references/ORG.md` — the charter spec and structural rules
- and the part this file never had: the rules for deciding **whether** to staff anyone at
  all, and at which tier

This file is deliberately a pointer and not a copy. It used to be generated; the generator
now writes `orgagent/references/roster.md`, so anything left here would be a frozen
duplicate drifting quietly out of date — the exact failure the "generated indexes are never
hand-edited" rule exists to prevent.
