Two decisions that run on every job

Choosing who does the work is only half of it. Whether four specialists were created or Alfred handled it alone, two more things get settled every time.

The part worth remembering

The org chart still exists and still says who is responsible for what. What changed is that it is now a reference rather than a payroll.

Before, all fifty-three roles were loaded into every conversation, including the ones about typos. Now the chart sits greyed out with only you lit, and a box lights up when something is genuinely running as it. Measured on identical requests, that removed about 16,000 units of setup from every session — roughly a quarter of what loads before any work begins.

How the shelf is actually built

The library isn’t a folder of documents Alfred reads. It’s three depths, and almost nothing is opened. One entry on that shelf — the org handbook — is what made removing the permanent roster possible at all.

The brain: plain files that write themselves

Separately from the skill shelf, Alfred keeps a memory — 353 markdown notes in an ordinary folder. Nothing about it is exotic: no database, no search index, no special application. What makes it work is that it fills itself in without being asked.
